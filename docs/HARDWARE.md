# 하드웨어 구성

무인샵형 프로토타입은 완제품 부품만으로 구성합니다. 납땜이나 케이스 제작 없이 따라 할 수 있습니다.

## 부품

| 부품 | 조건 | 비고 |
|---|---|---|
| 안드로이드 태블릿 | 크롬 브라우저가 돌아가는 기종, 후면 카메라 | 손님 화면. 가격표 촬영에 카메라를 씁니다. |
| 바코드 리더기 | 키보드 입력 방식(HID), USB 또는 블루투스 | 찍으면 숫자를 입력하고 Enter를 누르는 기본 설정 그대로 사용 |
| USB OTG 젠더 | 태블릿 단자에 맞는 것 | USB 리더기를 태블릿에 꽂을 때만 필요 |
| 태블릿 거치대 | 계산대에 고정되는 것 | 화면이 손님 눈높이에 오도록 |
| 바코드 스티커 | 인쇄된 바코드 스티커 롤 | 바코드가 없는 상품에 붙여 등록 |

구매 가격은 구매처와 시기에 따라 달라 적지 않았습니다. 직접 구매한 내역을 기준으로 채워 주세요.

## 연결 방법

### 방법 1 — 태블릿 한 대로 끝내기 (권장)

태블릿에서 서버도 함께 실행합니다. 주소가 `localhost`라 음성 입력이 그대로 동작합니다.

1. 태블릿에 [Termux](https://termux.dev)를 설치합니다.
2. Termux에서 `pkg install nodejs git` 실행 후 README의 설치 순서를 따릅니다.
3. 크롬에서 `http://localhost:8080`을 열고, 메뉴의 "홈 화면에 추가"로 전체 화면 앱처럼 띄웁니다.
4. 바코드 리더기를 OTG 젠더 또는 블루투스로 태블릿에 연결합니다.

### 방법 2 — 매장 노트북·미니PC에서 서버 실행

1. 노트북에서 `npm start`로 서버를 실행합니다.
2. 태블릿과 노트북을 같은 와이파이에 연결하고, 태블릿 크롬에서 `http://노트북IP:8080`을 엽니다.
3. 바코드 리더기는 태블릿에 연결합니다.

이 방식에서는 주소가 `localhost`가 아니어서 브라우저가 마이크 사용을 막습니다(음성 버튼이 나타나지 않음). 글 입력·바코드·가격표 촬영은 그대로 됩니다. 음성까지 쓰려면 HTTPS 프록시(예: Caddy)를 앞에 두세요.

관리 화면은 PIN으로만 보호되므로, 손님용 공개 와이파이와 같은 네트워크에 서버를 두지 마세요.

## 바코드 리더기 확인

메모장 앱을 열고 아무 바코드나 찍었을 때 숫자가 입력되고 줄이 바뀌면 그대로 쓸 수 있습니다.
줄이 바뀌지 않으면 리더기 설명서의 설정 바코드로 "Enter(CR) 접미사"를 켜 주세요.

## 손님이 태블릿을 벗어나지 못하게 하기

안드로이드 설정의 "앱 고정"(화면 고정) 기능을 켜고 키오스크 화면을 고정하면 손님이 다른 앱으로 나갈 수 없습니다.
