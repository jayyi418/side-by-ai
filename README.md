# Side by AI

소상공인이 직접 설치하고, 자기 가게 규칙을 말하듯 적어 설정하는 **오픈소스 AI 점원 키오스크**입니다.
태블릿 한 대와 바코드 리더기만 있으면 무인 매장에서 손님의 질문에 답하고 계산까지 안내합니다.

연세대학교 고등교육혁신원 워크스테이션 팀 **Side by AI**가 만들고 있습니다.
"사람을 대체하는 AI가 아니라 사장님과 손님 옆자리에 서는 AI"가 목표입니다.

> 현재 버전(0.1)은 **무인샵형**(빈티지·소품 매장) 프로토타입입니다. 아래 [한계](#지금-버전의-한계)를 꼭 읽어 주세요.

## 무엇을 하나요

| 기능 | 설명 |
|---|---|
| 대화 응대 | 손님이 글이나 음성으로 물으면 AI 점원이 상품 정보와 가게 규칙에 따라 답합니다. 손님이 쓰는 언어로 답합니다. |
| 가게 카드 | 사장님이 "우리 가게는 환불이 안 되고 사이즈는 실측으로 안내해줘"처럼 평소 말투로 적으면 그대로 응대 규칙이 됩니다. 코딩이 필요 없습니다. |
| 바코드 계산 | USB·블루투스 바코드 리더기로 상품을 찍으면 장바구니에 담깁니다. |
| 가격표 촬영 | 바코드가 없는 상품은 가격표를 카메라로 찍으면 AI가 가격을 읽고, 손님이 확인한 뒤 담습니다. |
| QR 결제 안내 | 합계와 사장님의 송금 QR을 보여 주고, 손님이 송금했다고 누르면 사장님에게 알림이 갑니다. |
| 사장님 호출 | 버튼을 누르거나 AI가 해결하지 못하는 상황이면 사장님 휴대폰으로 알림을 보냅니다. |
| 매출·응대 기록 | 하루 매출과 주문, 손님이 무엇을 물었고 AI가 어떻게 답했는지 관리 화면에서 볼 수 있습니다. |
| 오프라인 응대 | 인터넷이나 AI 연결이 끊겨도 상품 검색과 바코드 계산은 계속 동작합니다. |

## 준비물

- 태블릿 1대 (안드로이드, 크롬 브라우저)
- 바코드 리더기 1개 — 키보드처럼 입력되는 방식(HID)이면 됩니다. 시중의 USB·블루투스 리더기 대부분이 해당합니다.
- 서버를 실행할 기기 — 태블릿 자체(Termux) 또는 매장의 노트북·미니PC
- Claude API 키 (없어도 오프라인 응대로 동작)

부품과 연결 방법은 [docs/HARDWARE.md](docs/HARDWARE.md)에 있습니다.

## 설치와 실행

[Node.js](https://nodejs.org) 22 이상이 필요합니다.

```bash
git clone https://github.com/jayyi418/side-by-ai.git
cd side-by-ai
npm install
cp .env.example .env   # 필요한 값만 채우기
npm start
```

실행하면 주소와 관리자 PIN이 표시됩니다.

- 손님 화면: `http://localhost:8080/`
- 관리 화면: `http://localhost:8080/admin`

처음 실행하면 `presets/vintage-shop`의 예시 가게 카드와 예시 상품이 `data/` 폴더로 복사됩니다.
관리 화면에서 우리 가게 내용으로 바꾸세요.

## 설정 (.env)

| 값 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키. 비우면 오프라인 응대만 합니다. |
| `AI_MODEL` | 기본 `claude-opus-5-5`. 응답 속도나 비용이 부담되면 `claude-haiku-5-5`로 바꿀 수 있습니다. |
| `AI_EFFORT` | 응답 깊이. 기본 `low` (짧고 빠른 응대). |
| `ADMIN_PIN` | 관리 화면 PIN. 비우면 실행할 때마다 임시 PIN이 콘솔에 표시됩니다. |
| `NOTIFY_URL` | 사장님 호출·결제 알림을 받을 주소. [ntfy](https://ntfy.sh) 토픽 주소를 넣으면 휴대폰 푸시로 옵니다. |
| `PAYMENT_QR_URL` | 결제 화면에 띄울 송금 QR 이미지. `public/payment-qr.png`로 저장하고 `/payment-qr.png`를 넣으세요. |
| `PAYMENT_NOTE` | 결제 화면에 함께 보여 줄 문구(계좌번호 등). |

## 사장님이 하는 일

1. **가게 카드 쓰기** — 관리 화면 > 가게 카드. 환불·교환, 사이즈 안내 방식, 피팅룸 위치처럼 손님이 자주 묻는 것을 적습니다. 마이크 버튼으로 말해서 추가할 수도 있습니다.
2. **상품 등록** — 관리 화면 > 상품. 바코드 칸을 누르고 리더기로 찍은 뒤 이름·가격·실측 사이즈·상태를 적습니다. 바코드가 없는 빈티지 상품은 시중의 바코드 스티커를 붙여 찍으면 됩니다.
3. **입금 확인** — 손님이 "송금했어요"를 누르면 알림이 옵니다. 은행·간편결제 앱에서 입금을 확인하고 관리 화면 > 매출·주문에서 "입금 확인"을 누릅니다.
4. **응대 기록 살펴보기** — AI가 틀리게 답한 내용이 있으면 가게 카드나 상품 정보를 고칩니다.

## 구조

```
server.js          HTTP 서버와 API (Node 기본 모듈만 사용)
src/clerk.js       AI 점원: 가게 카드 + 상품 목록 → 프롬프트, 도구 호출, 가격표 인식, 오프라인 응대
src/store.js       상품·가게 카드·주문·기록 파일 저장소 (data/ 폴더)
src/session.js     손님별 대화와 장바구니
src/notify.js      사장님 알림
public/            손님 화면(index.html)과 관리 화면(admin.html)
presets/           업종별 예시 가게 카드와 상품
test/              자동 테스트 (npm test)
```

AI 점원은 세 가지 도구만 쓸 수 있습니다: 상품 검색(`search_products`), 장바구니 담기(`add_to_cart`), 사장님 호출(`call_owner`). 결제 처리나 가격 변경은 AI가 할 수 없게 되어 있습니다.

데이터는 모두 `data/` 폴더의 JSON·Markdown 파일이라 메모장으로 열어 고치거나 통째로 백업할 수 있습니다.

## 개인정보

- 음성은 브라우저의 음성 인식 기능으로 글자로 바뀐 뒤 그 글자만 서버로 옵니다. 브라우저 종류에 따라 음성 인식 과정에서 음성이 브라우저 제조사 서버로 전송될 수 있습니다.
- 가격표 사진은 인식에만 쓰고 저장하지 않습니다.
- 손님과 오간 대화 글은 응대 개선을 위해 `data/logs/`에 날짜별로 저장됩니다. 매장에 안내문을 붙여 손님에게 알려 주세요.
- AI 응대를 켜면 대화 내용과 가격표 사진이 Claude API(Anthropic)로 전송됩니다.

## 지금 버전의 한계

- **결제를 확인하지 못합니다.** 키오스크는 금액과 QR을 보여 줄 뿐이고, 실제로 돈이 들어왔는지는 사장님이 직접 확인해야 합니다. 카드 단말기(VAN) 연동은 없습니다.
- **가격표 인식은 손님 확인에 의존합니다.** 잘못 읽을 수 있으므로 가격표로 담은 상품은 주문 내역에 "가격표 인식"으로 표시됩니다.
- **음성 기능은 보안 연결에서만 동작합니다.** 태블릿에서 `http://localhost`로 접속하거나 HTTPS를 써야 마이크 버튼이 나타납니다. ([docs/HARDWARE.md](docs/HARDWARE.md) 참고)
- **한 매장, 한 대 기준입니다.** 여러 대가 같은 데이터를 동시에 쓰는 상황은 고려하지 않았습니다.
- 식당형(음성 주문 → 주방 주문지 출력)은 아직 없습니다.

## 다른 업종으로 바꾸기

`presets/` 아래에 폴더를 만들고 `shop-card.md`와 `products.json`을 넣은 뒤 `.env`의 `PRESET`을 그 폴더 이름으로 바꾸면 됩니다. 프리셋은 `data/` 폴더가 비어 있는 첫 실행 때만 복사됩니다.
